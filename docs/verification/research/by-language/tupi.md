## Phonology Check

- Source: Wikipedia Tupi language phonology, Navarro 2013
- Key patterns:
  - **No /l/ or /r/ (trill)** — Tupi has no lateral /l/ or trilled /r/
  - Consonants: p, t, k, ʔ, ᵐb, ⁿd, ᵑɡ, β, s, ʃ, ɣ, h, m, n, ɲ, ŋ, w, j, ɾ
  - Vowels: i, ɨ, u, ɛ, ɔ, a (with nasal counterparts ĩ, ɨ̃, ũ, ɛ̃, ɔ̃, ã)
  - Syllable structure: (C)V — **no consonant clusters, no coda consonants**
  - Glottal stop /ʔ/ between vowels and word-initially
  - Semivowels: û (/w/), î (/j/)
  - Note: European-origin names (Rio de Janeiro, etc.) would violate Tupi phonotactics
- Names flagged: **All 192 original names violated Tupi phonology** — contained consonant clusters (/st/, /rt/, /mp/, etc.), /l/ in positions where it shouldn't exist, and coda consonants. All replaced.
