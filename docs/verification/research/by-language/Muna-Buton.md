## Problem: Not a Single Language
"Muna-Buton" refers to the Muna-Buton languages, a subgroup containing multiple distinct languages:
- Muna (~270,000 speakers)
- Pancana, Kioko, Liabuku, Kaimbulawa, Busoa (smaller Munic languages)
- Buton languages: Kumbewaha, Lasalimu, Cia-Cia, etc.
- Tukang Besi, Bonerate

These languages span Muna Island, Buton Island, and surrounding smaller islands. Without specifying WHICH language, assigning valid toponyms is impossible.

## Muna Language Phonology (from Wikipedia Muna language article)
Source: https://en.wikipedia.org/wiki/Muna_language

**Syllable structure**: ONLY CV and V — open syllables ONLY (no consonant clusters, no coda)

**Consonants**:
- Plain voiceless: p, t, k
- Prenasalized voiceless: ᵐp, ⁿt, ᵑk
- Plain voiced: b, d̪ (dh), d, g
- Prenasalized voiced: ᵐb, ⁿd, ᵑg
- Implosive: ɓ (bh)
- Fricative voiceless: f, s, h
- Prenasalized fricative: ⁿs
- Fricative voiced: ʁ (gh)
- Nasals: m, n, ŋ (ng)
- Trill: r
- Lateral: l
- Approximant: ʋ (w), (j/y)

**Vowels**: /a/, /i/, /u/, /e/, /o/ — five vowels, freely combine into VV (long vowels) or VVV sequences

**Example words from source**: kaindea 'plantation', padamalala 'citronella', karadhaa < Malay kerja 'work'
