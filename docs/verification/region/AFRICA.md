# Africa Region Context

## Geographic Scope

Africa has extreme linguistic diversity — over 2,000 languages across 6 major families:
- **Afro-Asiatic** (North Africa, Horn, Sahel): Arabic, Berber, Hausa, Amharic, Somali, Oromo
- **Niger-Congo** (Sub-Saharan): Swahili, Yoruba, Zulu, Igbo, Lingala, Wolof, Akan
- **Nilo-Saharan** (East/Central): Dinka, Nuer, Luo, Maasai, Songhay
- **Khoisan** (Southern Africa): Nama, Khoekhoe, Sandawe, Hadza
- **Austronesian** (Madagascar): Malagasy

## Common Verification Challenges

### 1. Languages with colonial names
Many African entries contain French/English/Portuguese colonial place names. These should be replaced with indigenous names where possible. A colonial name is indigenous if speakers of the language use it (e.g., "Lagos" is Yoruba, not colonial).

### 2. Administrative units masquerading as places
African entries frequently contain province/state names (e.g., "Far North Region", "Upper East Region"). These must be removed. Replace with specific villages/provincial capitals.

### 3. Micro-languages in the Sahel and Cameroon
The Sahel and Cameroon Grassfields have extreme linguistic fragmentation. Some languages have <1000 speakers in 2-3 villages. For these:
- Search for the specific commune/district Wikipedia page — it lists villages
- Use Ethnologue for specific village names
- If <30 names found after thorough search, mark WAITING

### 4. Dialects vs. languages
Many entries are labeled as "dialects" (e.g., "Berber (Morocco)"). Treat these as language variants — verify names specific to that dialect's region.

### 5. Cross-border languages
Languages like Hausa, Fula, Swahili, and Arabic span multiple countries. Verify names from each country where the language has been spoken.

## Key Sources for African Verification

1. **Wikipedia**: `https://en.wikipedia.org/wiki/<Language>_language`
2. **Wikipedia districts/communes**: `https://en.wikipedia.org/wiki/<District>_District` — lists villages
3. **Ethnologue**: `https://www.ethnologue.com/language/<code>/`
4. **GeoNames**: `https://www.geonames.org/search.html?q=<name>&country=<code>`
5. **ALCAM** (Linguistic Atlas of Cameroon): For Cameroonian languages specifically

## Name Patterns by Family

- **Bantu**: Prefix-v-root-suffix patterns (e.g., Umu-, ama-, isi-, ubu-; -land, -ville, -burg)
- **Afro-Asiatic**: Root-based with affixes (e.g., Harar, Amhara, Afaan)
- **Nilo-Saharan**: Often compound names (e.g., Bor, Torit, Kapoeta)

## Tags

Tags must be ISO 3166-1 alpha-3 or continent codes (AFR, EUR, ASI, OCE, NAM, SAM) for generic context.
