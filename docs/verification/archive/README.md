# ARCHIVED — do not use these to make decisions

Everything in this directory is **historical**. It is kept only so that earlier
research is not lost, and so that a claim made at the time can be traced.

## Why this directory exists

Between June and September 2026 the verification effort accumulated 84 documents
in `docs/verification/`. They were all hand-maintained, all written by different
agents at different times, and they contradicted each other. A representative
sample, all of which were live at the same time:

| Document | Claim |
|---|---|
| `checkpoints/asia-checkpoint.json` | 0 WAITING, 4,082 entries COMPLETE |
| `checkpoints/europe-checkpoint.json` | 100% verification rate, 0 WAITING |
| `checkpoints/noceania-checkpoint.json` | "RESTART — previous work was incomplete" |
| `checkpoints/north-america-checkpoint.json` | "HONEST STATUS: previous checkpoints falsely marked entries as verified"; 180 entries untouched |
| `TRACKER.md` | "ALL PREVIOUS LOGS MARKED UNVERIFIED"; 513 entries contaminated |
| `reports/africa-honest-status.md` | contradicts `reports/africa-progress.md` |
| `QUICK-START.md` | "Current State (Baseline), run on 2026-06-18" |

An agent picking up the work had no way to tell which document to believe, so
each one trusted a different one. Several of the "COMPLETE" claims were not
merely stale: 1,794 entries were marked `COMPLETE` in the data while holding
fewer than the required 25 names, and 5,689 of the names that made up those
counts were synthetic padding generated by appending a random letter to the
language name.

None of these documents was updated after 2026-08-25, while thousands of seed
changes were being committed.

## What replaced them

Two documents, both in the parent directory:

- **`AGENT-PLAYBOOK.md`** — the workflow. Claims nothing about current state.
- **`STATUS.md`** — the current state. **Generated** from the data by
  `pnpm namebase:status`, so it cannot be hand-edited and cannot go stale or
  contradict itself.

If a number you need is in neither, produce it with `pnpm namebase:verify`.
Never from a file in this directory.

## A warning about the per-language research logs

`../research/by-language/` is retained as evidence and some of it is genuinely
useful. But treat it as a **starting hint, never as proof**. These logs were
written before the integrity gate existed, and at least some of them recorded
verifications that did not hold up. If you use one, re-verify the names it
claims before editing the data.

## Contents

- `MASTER-PLAN.md`, `QUICK-START.md`, `verification-protocol.md` — superseded
  process documents, each of which claimed to replace all previous ones.
- `TRACKER.md`, `checklist.md`, `verification-tracker.md`, `verification-log.md`
  — parallel task trackers, mutually inconsistent.
- `agents/` — per-continent agent briefs.
- `checkpoints/` — 14 JSON checkpoint files for 7 continents, several
  duplicated under different filename casings, all disagreeing.
- `reports/` — progress and audit reports, including the "honest status" report
  that contradicts the progress reports beside it.
- `research/batch-*.md`, `research/SESSION-*.md`, `research/PROGRESS.md` —
  session and batch progress notes.
- `DEEP_VERIFICATION_REPORT.md`, `SUBAGENT-PIPELINE.md`, `ENTRY-PROMPT.md`,
  `AGENT-COORDINATION.md` — pipeline and coordination design.
