**Note on field `b` (bases):** In namebases-asia.js, the `b` field stores geographic seed regions for generation. These are predominantly **administrative divisions** (provinces, districts, communes, counties) — NOT towns/cities. This is by design: the generator uses these as sampling regions, and then picks settlement names from within them. So listing district names in `b` is correct behavior, but they should not be labeled as "towns" downstream.
