### Method
For each entry:
1. Web search the language name + "place names" / "villages" / "Papua New Guinea" / etc.
2. Verify each name in b: field is a real place named IN or strongly associated with the language
3. Check phonotactic consistency with the language family
4. Verify minimum thresholds (80+ major, 50+ medium, 30+ small)
5. Document sources and status

### Status Key
- ✅ VERIFIED: All names checked against web sources
- ⚠️ PARTIALLY VERIFIED: Some names verified, others unverifiable despite effort
- ❓ UNVERIFIED: Could not verify most names
- ⏳ WAITING: Cannot verify after extensive effort (document why)
