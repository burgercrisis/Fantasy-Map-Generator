# Product Overview

This is a fork of Azgaar's Fantasy Map Generator - a free web application that helps fantasy writers, game masters, and cartographers create and edit fantasy maps.

## Key Features Added in This Fork

- **Language Mixer System**: A Markov-based system that can "mix" different languages to generate novel placenames that feel authentic but don't exist in reality
- **Fantasy Race System**: Integrated race system with campaign setting sets that works alongside the cultures system
- **Enhanced Language-Race Integration**: Improved wiring between races, cultures, and languages

## Current Development Focus

1. Language Mixer Rules and compliance
2. Races ↔ Cultures decoupling 
3. Language behavior across different races and cultures
4. Underdark generation system
5. Rendering upgrades to DeckGL hybrid
6. Individual character system
7. Heightmap landforms and world builder
8. Evolving world simulation layer

## Target Users

- Fantasy writers and worldbuilders
- Game masters (D&D, Pathfinder, etc.)
- Cartographers and map enthusiasts
- Anyone creating fictional worlds

The application generates interactive, highly customizable fantasy maps with detailed political, cultural, religious, and geographical features.
